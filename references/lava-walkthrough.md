# 熔岩打击怎么搭

目标是让有「熔岩打击」的英雄普攻命中敌人时有 20% 概率引发范围火焰，每名攻击者独立冷却 5 秒。先按 F4，建两个已启用的触发器，分别命名为 Setup 和 Impact。下文引号中是本版 KKWE 节点定义的中文标题。

## 先做准备

- 在物体编辑器创建标记技能并给测试英雄。样例从物品护甲加成技能 `AId1` 派生，原始 ID 为 `ALav`，护甲加成设为 0。本图已有相同 ID 时，选自己的技能并在下面的条件中同步替换。
- 在变量编辑器创建四个非数组全局变量：`LavaClock`（计时器）、`LavaCD`（哈希表）、`LavaChance`（整数）、`LavaProcs`（整数，初值 0）。样例生成的初始化脚本会为计时器变量创建实例。
- 在触发编辑器的地图自定义脚本区加入完整的 [LavaBurst 函数](../assets/LavaBurst.j)。最后一步动作要调用它。它以受伤单位为圆心，给范围内仍存活的敌人造成非攻击火焰伤害；攻击者是伤害来源。

## Setup：地图开始时执行一次

事件选「地图初始化」。按顺序添加四个动作：

1. 「<1.24> 新建哈希表」。
2. 「设置变量」→ LavaCD =「最后创建的哈希表」。
3. 「自定义代码」→ 填 `call TimerStart(udg_LavaClock, 86400.0, false, null)`，用它计量这局游戏已经过去的秒数。这个样例适用于计时器到期之前。
4. 「设置变量」→ LavaChance = 20。第一次验证可临时填 100。

## Impact：普攻命中后检查

| 加在哪里 | 在编辑器里怎么选、参数怎么填 |
|---|---|
| 事件 | 选「任意单位伤害事件」。选好后，触发树显示“任意单位 接受伤害”。此项来自 ydwe 模块，内部键为 `YDWESyStemAnyUnitDamagedRegistTrigger`。 |
| 条件 1 | 新建「布尔表达式」，点击左值，选择函数「是攻击伤害 [JAPI]」，比较符选等于，右值选 True。这个函数来自 japi 模块，内部键为 `YDWEIsEventAttackDamage`，没有输入参数。直接在本次伤害回调中判断，等待后无法可靠取得这次事件的标志。 |
| 条件 2 | 新建「实数」，左值选「伤害值」，比较符选大于，右值填 0。 |
| 条件 3 | 新建「整数」，左值选「单位技能等级 [R]」。单位填「伤害来源」，技能选自己的熔岩打击，比较等级 > 0。 |
| 条件 4 | 新建「布尔表达式」，左值选「是玩家的敌对单位」。单位填「触发单位」，玩家填「单位所有者（伤害来源）」，判断等于 True。这里的触发单位是受伤者。 |
| 条件 5 | 新建「实数」。左值选「逝去时间」，计时器填 LavaClock。比较符选 ≥。右值选「<1.24> 从哈希表提取实数 [C]」，表填 LavaCD，主索引选「<1.24> 获取对象的h2i值 [C]（伤害来源）」，子索引填 0。尚未记录时取值为 0。 |
| 动作 | 新建「If / Then / Else (多项功能)」。在它自己的条件分支加「整数」：左值「随机整数」从 1 到 100，判断 ≤ LavaChance。下面两个动作依次放进 Then，Else 留空。 |
| Then ① | 「<1.24> 保存实数 [C]」：表、主索引和子索引与条件 5 相同。保存的值选「算术运算 Lv2」，填「逝去时间（LavaClock） + 5.00」。先记冷却，再造成伤害。 |
| Then ② | 「自定义代码」：填 `call LavaBurst(GetEventDamageSource(), GetTriggerUnit(), 250.0, 150.0)`。250 是半径，150 是基础伤害。 |

上述比较、哈希表和变量节点取自本例的 ydwe 定义。需要核对树的层级和内部键时，打开 [Impact 原始 LML](../assets/Impact.lml)。目标地图若用其他系统产生带“攻击伤害”标志的技能伤害，需先查那个系统的标记方式。

## 进游戏怎么验

把 LavaChance 设为 100，保存编译并测试当前地图。让有技能的英雄 A 普攻敌人一次，应出现火焰，附近敌人掉血、范围外敌人不受这次范围伤害。A 在 5 秒内再普攻，应只有普通攻击；另一名同样有技能的英雄 B 此时普攻，应能独立触发。等 A 的冷却结束，只用普通的非攻击伤害技能命中，预期不会触发；再普攻应能触发。将概率改为 0 再验证一次，最后恢复为 20。

原样例在 Warcraft III 1.27.0.52240 单机通过七项断言，记录为 FAIL_BITS=0、PROCS=3。换图后优先复测上面的对照。节点找不到时，核对当前 KKWE 启用的 ydwe、japi 和目标图使用的扩展；同名近似节点要核对事件时机、参数及返回类型。
